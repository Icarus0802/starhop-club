# Learned value v1：独立审查边界

审查日期：2026-10-10。对象为 `scripts/train-value.cjs`、`benchmarks/value-features.cjs`、`benchmarks/learned-value-v1.json` 和隔离候选 I。正式 AI 未因此替换。本次只读源码、数据及模型元信息，不运行搜索、训练或修改正在对战的 v1 权重。

验证样本的损失参与每五个 epoch 的最优 checkpoint 选择，因此该重合样本进入了选择过程。**尚未重训对照，未证明删除它会改变 bestEpoch 或对战结果。** 不能写“无数据泄漏”；按整局／开局分组仍可能在后续收官汇合到同一棋盘。

此次检索未发现训练／测试或验证／测试的相同完整局面，加入 180° 旋转并交换双方颜色的规范化后也未发现新的跨集重合。这个结论只针对已保存的 1,649 个抽样状态和这两类规范化，不证明全部轨迹、近似局面或特征向量完全独立。最终测试只有 2 个开局组、4 局／120 样本，预测指标不足以验证强棋力。

## v2 的可执行修正

保留正在评测的 v1 模型、哈希、棋谱和上述限制，不中途改参数。v2 在 `buildRows` 后审查规范化跨集重合，先保留训练集，再从验证／测试指标剔除与训练重合的样本；验证与测试重合也应处理并记入清单。或者合并发生重合的整开局组后重新拆分。剔除数、剩余局数与每局权重需重新计算；不能将被剔除样本计入“独立测试”分母。

最终棋力验收仍使用模型冻结之后的新开局。现有旧版比赛虽曾称为候选的 heldout，进入本次模型训练后就不能继续充当该模型的未知棋力测试。未来更改模型超参数、特征或训练数据后需要新的封存验收组。

## 静态代码检查结果

- 特征仅读取当前棋盘的匹配、滞后、起营、到达、相邻桥梁及真实运输项；没有读取结果、冻结续走、步差或搜索评分。标签经共享规则合法回放得到，工程截断和人工棋谱按元数据排除。当前测试集没有传入 optimizer 或验证 checkpoint 比较。
- 候选 I 保留原 H 的完整合法走法生成及最终共享规则路径验证；模型没有另造动作或裁掉合法落点。geometry cache 只依自方占位，运输 cache 依双方完整占位；传统／学习目标切换会清理缓存和 TT，静态未发现该切换的评分串用。
- 运行时模型加载目前仅核对 format、theta 长度及 featureVersion，弱于离线 `validateModel`。v2 应复用严格校验，检查数值有限、特征顺序／尺度、phase、bias、scoreScale 和源码契约；畸形模型拒绝加载或明确回退，避免非有限评价被误当解出胜负。此项是契约加固，当前保存的 v1 数值已通过现有离线校验。
- 对战工具的引擎元信息目前主要记录 JS 源码 SHA，而 I 还依赖单独的 JSON 权重；完整评测证据还应记录该模型文件 SHA 和版本。以后只改权重不改 JS 会产生相同引擎源码 SHA，不能据此认为评价相同。v2 应保留 v1 文件、使用独立模型文件名，并明确记录实际加载的版本，避免进程内 `require` 缓存影响复测。

这是一个**实际由结果监督拟合的十二参数分阶段线性价值模型**，不是神经策略／价值网络，也没有学习新的特征表示。参数和留出预测指标能够重现，不等于已提升实战、更不等于冠军棋力。I 的等时对战结果应在批次全部完成后单独报告，稳定领先旧版至少五个自方完整回合的标准保持不变。
