# 星跃棋社 1.4：青玉暖金棋室、完整跳跃与实验趋势分析

上一手不够明显、棋子缺少质感、结构趋势难以理解，本 PR 面向 1.4 正式界面更新：双人对局由青玉与暖金统一棋手、营地、棋子及趋势颜色；完整连续跳逐段播放并保留起点、落点与文字路径，支持重播和减少动态效果。快速 AI 回复等待上一段动画完成，暂停、结束、悔棋与复盘会取消待执行回复。

分析区显示从当前棋手视角出发的结构评分、真实可达跳路、后子堵截、未填营孔与逐手趋势。新增实验模型百分比来自真实训练的 linear-v2，只支持双人短跳、未锁营；胜1、和0.5、负0使它表示和棋折半的预期得分，尚未校准，不能视为对真人或特定对手的胜率。规则引擎独立验证当前方能一步填营时展示明确旁白，不人为上调模型值；规则终局与手动停止分别说明。
