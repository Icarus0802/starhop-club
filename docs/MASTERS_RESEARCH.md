# 中国跳棋大师实战与评测题研究

核验日期：2026-10-10。研究对象是 121 孔、每方十子、传统单跳的中国跳棋。主要来源是华夏的汉子和挑战者本人公开发布的文章、实战动态图、比赛视频索引。这里将作者主张、已核验规则事实、原创测试题和待验证推断分开记录；不宣称已训练模型或达到冠军棋力。

## 对当前 AI 最有用的公开理论

1. **比较双方完成运输的速度。** 挑战者的[计算文章](https://tiaoqi.top/thread-408.htm)讨论多回合相对进度、为己方搭桥与拆桥、为对方搭桥与破桥。工程上应在候选落子后的真实连跳图上，分别测量其他九子的运输变化和对手可利用的桥梁；不能只奖励当前棋子的前进距离。
2. **堵截也要计算自己的损失。** 华夏的汉子的[局势分析](https://tiaoqi.top/thread-270.htm)给出撤掉己方桥梁却未堵住对手另一条路线的反例。建议对候选分别估计己方追加调整步数和对方最低运输成本增量；只用邻接数或堵住一个落点容易把自损误判为好棋。
3. **后子位置要和可借力路线结合。** [宏观区域价值](https://tiaoqi.top/thread-816.htm)将靠近己方出发营的低位后子、中心与边缘通道分开讨论。中央通常便利，但相互借力的边线棋形存在例外。不能将“永远先走最后一子”或“边缘永远扣分”当作定理。
4. **收官需要架子及装填顺序。** [基本框架](https://tiaoqi.top/thread-231.htm)说明若先填满浅层、拆掉架子，进入深孔需要更多调整；横向静着有时能缩短总运输。终点匹配距离只是下界，应检查深孔的跳入桥梁、路线是否堵住以及架子何时可以撤。
5. **区分基础步与调整步。** 挑战者的[僵局调整](https://tiaoqi.top/thread-118.htm)讨论双方路线重叠、走动给对手搭桥，以及替代路线的代价。残局应更直接比较实际完成手数、轮到谁走和互相让路成本；不能把剩余孔数直接当成胜率。
6. **进营路线必须匹配空孔。** 华夏的汉子的[四大点位应用](https://tiaoqi.top/thread-293.htm)强调外部棋子的路线应对应营内未填孔位。建议保留全十子与全十孔的分配，同时评价可达性与桥梁，不以最近孔位贪心装填。

以上是针对引擎的原创归纳，不复制收费开局库、私教课程或私人群资料。文章中的个别经验百分比不是已校准的统计获胜率。

## 已验证的原创撤桥测试

以下是合成静态局面，启发来自公开理论，**不冒充大师实际棋谱，也未证明从初始局面可达或整盘最优着法**。两方各十子，单跳，目标营不锁定。p3 从下方向上走。

```js
const own3 = ['M7','L7','J8','C6','C7','C8','D5','D6','D7','D8'];
const opp0 = ['M5','N6','N7','N8','O6','O7','O8','P6','P7','Q7'];
const rules = { jump: 'short', goalLock: false };
```

使用当前 `E.pieceMoves` 完整枚举，M7 可经 L7 和 J8 借力，合法连续落点为 **M7 → K8 → I9**，纵向前进四行。如果先走同样合法的 **L7 → K7**，后子 M7 的最大即时纵向前进变成一行，只剩 L6/L7 的单步。这里的借力是有空落点的实际跳跃路径，邻近但无法落地不计入。

该题能验证撤桥前后的后子可达性与候选评分，不能单独证明应该永远优先走 M7。后续应添加对手一步会封 I9、替代桥梁能及时形成等反例，防止奖励一个固定形状。

建议扩充的测试集包括：深孔装填先后、保留桥梁而后子通过、堵单一落点却能绕路、后子横移脱困、边线双子互助、双方残局交错让路。每题保存完整局面、规则、轮到谁、正确性依据和时间预算；“最优着”只由解算器或明确大师逐着讲解确认。

## 数据及棋力验收边界

### 四个留出局面对比（首次测量）

可复现命令为 `node benchmarks/master-holdout.cjs`，完整输出为忽略目录的 `arena-results/master-holdout.json`，带被测源码 SHA256、实际用时、其它九子真实连跳增量、对手可达性变化和规划器预测线路。这里“20 着后”表示已走二十着，比较第 21 着；四题均为华夏的汉子走。

| 已走着数 | 实际大师着 | Team 350ms | Fast PVS 350ms | Adversary 候选 350ms | 旧 1.1 最高 900ms |
|---|---|---|---|---|---|
| 20 | M7→K6 | M7→K6 | M7→K6 | M7→K6 | M7→K6 |
| 40 | G5→E6 | G5→F4 | J8→H9→F8 | G5→E6 | J8→H9→F8 |
| 60 | K9→I8→G7 | E8→D8 | G9→F9 | E8→D8 | G9→F9 |
| 80 | I9→G10 | D6→B7 | F7→H8→F9 | I9→G10 | I9→G10 |

20 着后的大师着使其它九子最大即时运输增量合计增加六，说明真实搭桥特征能识别当前子前进之外的收益。60 着后大师先运较后棋子，Team/Adversary 先填一个营孔，但其预测线路第三个自方回合才走同一后子；这个差异值得验证装填先后和对手应手，不能仅凭不同着断言错误。80 着后 Team 先填深孔，候选和旧版先调整 I9，体现规划顺序差异。

Team 实测 167–238ms、完成八个规划回合；Fast 约 350ms、深度五；Adversary 265–350ms、七至八个回合；旧版约 900ms、深度四。规划回合数与搜索 ply 深度的单位不同，不能直接比较“谁更深”。预测的对手线路是启发式假设，未证明对手一定这样走；不同算法的评分也不能横比为胜率或人类等级分。这轮没有按“同着率”选正式引擎。

真实棋谱转录时记录原始链接、棋手、日期、规则、先后手、原作者结果，以及每着的从点/终点。用规则引擎从初始局面回放；每步必须合法、棋子数恒定、相邻两帧只移动一颗当前方棋子。GIF 无法确认连跳中间路径时，只将路径标为规则引擎生成的合法路径。公共 GIF 的事实性着法可以独立转录，但不将完整媒体、文章图或私有附件复制到发布包。

大师实战应先做留出评测，检查 AI 在相同局面、相同预算下是否避免明确坏棋；不能把大师最终获胜方的每一步当成最优标签。当前用公开理论改进的是棋形和运输评价特征，并做自战检验；这份真实大师棋谱用于转录、展示与留出局面分析，没有据此训练神经网络权重。少量自战或对旧版获胜证明的是相对改进，无法验证人类段位、冠军水平或“天下无敌”。
