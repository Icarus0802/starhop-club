# 星跃棋社 · 正式版 2.0.0

下载 `Starhop-Club-2.0.0-Windows-x64.zip`，**全部解压后双击“启动跳棋.cmd”**。包含运行时和本机 Kata 一子跳引擎，无需安装 Node 或 npm 包。首次运行模型可能需要数分钟显卡调优；棋室显示“本机神经网络已就绪”后，最高档使用原生模型。结束后双击“退出跳棋.cmd”。

Windows 10/11 x64；原生模型需要 OpenCL 显卡驱动及 Visual C++ 2015–2022 x64 运行库。无法启动模型时自动退回内置浏览器 AI。Mac、Linux 或只想轻量试玩，可下载 `Starhop-Club-2.0.0-Browser.zip`，解压打开 `index.html`；此版使用浏览器 AI，不包含神经网络棋力。

2.0 更新：
- 最高档接入经过实机验收的 Kata 预训练模型，双人相邻跳适用，其他规则与不支持的局面自动回退。
- 五组开局交换先后手，对旧最高档 10 胜 0 负，平均领先 3.3 个收官回合。双方预算 350ms；实测新引擎平均315ms，存在计时抖动。该结果来自 RTX 3060 Laptop 实机，不等同于任意设备或真人胜率。
- 石墨默认主题、可选配色、自定义图片背景；取消立绘，支持全屏棋盘。
- 保留局势估计、走势、入营进度、AI 思考状态、棋谱与复盘。
- 修复重复局面与胜负距离缓存问题；补充离线工作线程、模型失败回退和过期回复测试。
- 免安装启动器、同版本重复启动识别、端口冲突处理、后台服务退出入口。

棋谱与背景保存在浏览器本地；升级前可导出 JSON。联网对战和账号排名尚未提供。源码与第三方许可随包提供，发布文件附 SHA-256 校验。
