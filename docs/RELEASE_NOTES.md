# 星跃棋社 · 正式版 1.1

上一手现在持续显示起点、落点、箭头、连跳编号和完整路径，可动画重播。窄屏棋盘放大、底部导航及更大点击范围；已有棋谱兼容并保留。

AI 默认每步预算最高从 15 秒降到 1.5 秒。搜索加入 PVS、射线预计算和走法复用；评估双方借力、出口、落后棋子。分析面板新增运输风险和双方风险棋子定位。

17 项自动测试通过，包括实际 28 手堵塞棋谱和 PVS 与全宽 Alpha-Beta 完成深度一致性。多种开局交换先后手，新版与 1.0 在相同 250ms 下为 5 胜、2 负、1 和。完整对照证据见 docs/benchmarks 与 VALIDATION.md。

这是首个正式软件发布，不代表达到冠军棋力。没有训练好的神经网络；在线匹配、账号和排名尚未实现。
