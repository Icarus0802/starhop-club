# 星跃棋社 · 正式版 1.2.0

这版重点降低等待时间，并保留真实可检查的对照证据。五档默认预算为 60 / 80 / 120 / 220 / 350ms；最高使用 Fast PVS，中档使用团队运输规划。长跳和目标营锁定自动采用 Fast。上一手起落点、连跳路径与动画继续保留，完善复盘、会话和 AI 请求取消流程。

新增华夏的汉子与浪潮九霄 2017、2019 两盘公开实战：共178着，逐帧棋子数、每着合法性、初始与终盘均已验证，附原始来源。原平台先手仅快一着可算和；本程序即时满营规则显示胜者，记录明确区分，未编造动态图里没有的后手补齐着。

内部配对结果：Fast350 对 Team350 为4胜0负；Fast350 对旧最高900 为2胜2负；Team250 对旧最高250 为6胜2负。完整记录在 [1.2 benchmark](benchmarks/1.2/)；其它失利实验见[验证记录](VALIDATION.md)。发布前45项自动测试全部通过。

这不是人类等级评定，也没有证明可以战胜冠军。没有加载第三方模型或完成神经网络训练；当前提供本地练棋、复盘和分析，联网匹配与排名尚未实现。
