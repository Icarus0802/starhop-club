# 星跃棋社 · 正式版 1.3.0

东方轻幻想棋室：曜石背景、青玉棋盘与暖金细节，加入原创成年东方棋手立绘。立绘由本会话内置 imagegen 生成，透明 WebP 约277KiB；完整提示词与来源见 [设计记录](DESIGN_1_3.md)。

宽屏中以棋盘为中心，将棋手、分析和操作明确分层；窄栏与手机使用紧凑布局、底部导航。新增深浅配色和专注模式；搜索、复盘与运输细节可展开。上一手起落点、连跳路线与重播保留。

棋盘支持单一 Tab 入口、方向键浏览、Enter / Space 选子落子；选子后的重绘保留焦点。走势支持左右键逐手复盘，AI落子重绘后保留焦点。外观偏好独立于棋谱保存，切换主题或专注模式不会取消 AI 思考，不会改写当前对局或大师来源。手机主要操作44px高，短屏自动收起立绘，避免导航遮挡。

完整55项自动测试通过，六种浏览器窗口尺寸、深浅主题、专注模式、大师中盘与40手AI自战经过实测。界面图标内嵌，避免双击离线版时外部SVG引用受浏览器来源策略限制。

AI 内核、默认预算和规则沿用1.2；两盘华夏的汉子实录共178手继续可复盘与接手挑战。当前不包含联网匹配、账号排名或训练后的神经网络。本次发布不以视觉更新宣称棋力提高。验证与浏览器实测记录见 [VALIDATION](VALIDATION.md)。
