接入官方 Kata 一子跳模型，在本机 RTX 3060 Laptop GPU 上推理，保留通用 JS 搜索作为不兼容局面和超时的回退。先用独立开局筛选两局，均胜、收官距离均为 4；随后冻结程序、模型和适配器散列，用全新的五组八手开局换先进行十局正式对照。没有在正式对照过程中修改引擎或排除对局。
