星跃棋社 2.0.0

Windows 完整版：将 ZIP 全部解压到有写入权限的文件夹，双击“启动跳棋.cmd”。
自带 Node，无需安装开发环境。玩完双击“退出跳棋.cmd”关闭后台服务。
首次神经网络加载可能需要数分钟调优。看到“本机神经网络已就绪”后，最高档才使用 Kata。
需要 Windows 10/11 x64、支持 OpenCL 的显卡驱动及 Visual C++ 2015–2022 x64 运行库。
模型无法启动时自动使用浏览器 AI，仍能正常玩。长跳、锁营、多人及侧营局面使用内置搜索。

浏览器轻量版 / macOS / Linux：直接用现代 Chrome、Edge 或 Firefox 打开 index.html，离线可玩。
此方式不包含本机神经网络棋力，支持棋谱、复盘、外观和内置 AI。

存档和自定义背景保存在当前浏览器中。换浏览器或端口前，请导出 JSON 备份。
默认地址 http://127.0.0.1:5173/；端口被占用时自动尝试后续端口。
不上传棋谱，不需要账号。不包含在线匹配或多人联机。

AI 对照：本次本机测试对原最高档 10 胜 0 负，平均领先 3.3 步；非真人等级承诺。
规则、设备、预算与收官计量方式见 README 和验收记录。
